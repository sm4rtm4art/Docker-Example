# Docker Learning Path

Build, run and troubleshoot containers through a practical Task API. Choose **Python**, **Rust** or **Java**, then follow the same Docker exercises with your chosen implementation.

Start with [environment setup](00-prerequisites/index.md) and work through modules 00–10. Plan roughly 12–17 hours for one track, plus time for troubleshooting. The final **Beyond Docker** module is optional.

Every module gives you a goal, an experiment and a check. Before running a command, predict what will happen; afterwards, compare the result with your prediction. Keep a short record of commands, observations and explanations in your own notes.
